# Decision Journal

Append-only log of every status change. Never edit old entries. When an idea moves stage, gets killed, or gets revived, you add a row here; you do not rewrite history.

> **Track tagging:** Rows carry a `Track` field (final column), either `solo` (the bootstrapped portfolio in `ideas/`) or `venture` (the VC-backed track in `ventures/`). Rows without a Track value default to `solo`. Append-only; never edit prior rows.

> **Format note:** keep rows terse, a decision plus one line of reasoning. Long analysis belongs in the idea README, not a table cell. Use `Created (Stage)` for a new idea and `A -> B` for a stage change.
